# Willkommen bei Markdown Studio

Ein moderner Editor für **Markdown** – mit Live-Vorschau und praktischem Export.

## Schnell loslegen

- Schreibe links deinen Markdown-Text.
- Sieh rechts direkt das formatierte Ergebnis.
- Lade dein Dokument als **.md** oder **.txt** herunter.

### Formatierungen

Du kannst Text **fett**, *kursiv* oder ~~durchgestrichen~~ darstellen. Auch [Links](https://www.example.com), Inline-Code wie `const x = 42;` und Zitate sind möglich.

> Tipp: Nutze die Werkzeugleiste oder Tastenkürzel für häufige Formatierungen.

### Aufgabenliste

- [x] Dokument schreiben
- [x] Vorschau prüfen
- [ ] Datei exportieren
